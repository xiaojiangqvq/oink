指针尾迹增强版完整安装程序
基于 Oink 0.3.4 的第三方修改版，不是官方发行版。
版本：0.3.4-inhouse.109（build 109）

两台 Windows 电脑分别安装
1. 双击 PointerTrail-Setup.exe。新电脑无需先安装原版，已有 Oink 无需先卸载。
2. 点击“安装 / 更新增强版”，正常确认 Windows 管理员权限提示。
   如果电脑缺少 WebView2，请先在窗口中阅读微软许可并勾选同意。
   安装包已包含微软原版离线运行时，不要求另外下载。
3. 安装完成后点击“打开 Oink”。若提示重启，请先重启 Windows。
4. 在“设置 → 键鼠”选择尾迹模式、颜色、指针样式和大小。

适用于 Windows 10 1809 及更新版本的 x64 Windows。
安装会短暂退出 Oink，请使用当前电脑自己的键盘和鼠标。
原有设备配对、屏幕布局和设置会保留。两台新电脑仍需各自首次配对。
不要把某台电脑的 Oink 用户数据复制到另一台，以免复制设备私钥和身份。
已有启动登录选项会保留；新电脑可在应用设置中自行启用登录启动。
已安装较新构建时，本安装程序会拒绝降级。相同构建号的不同发行版也会拒绝覆盖。
相同增强版再次运行安装程序可修复安装。

尾迹与指针
原版升级或新安装默认保留快速画圈触发，可在设置中切换“移动即显示”。
旧个人“移动就显示”补丁升级时，只在缺少模式设置时迁移为移动即显示；已有选择不会被覆盖。
若自动迁移遇到错误，安装窗口会提示；此时新版仍已安装，可在设置中手动选择。
指针样式使用 Windows 自带资源，并影响此 Windows 用户的全局主箭头。
退出 Oink 不会撤销所选样式；要恢复之前的主箭头，请在设置中选择“原系统样式”。

日志、源代码与旧备份
安装窗口的“查看日志与源代码”打开本次工作目录：
C:\ProgramData\OinkTrailEnhancedInstaller\<本次编号>
其中包含 MSI 日志、完整修改源码、补丁、安装程序源码与许可证。
旧个人补丁成功升级后，其标记和私有备份会归档到：
C:\ProgramData\OinkTrailEnhancedInstaller\private-backups\<本次编号>
这些私有备份仅供当前机器恢复参考，不应分享或复制到另一台机器。
归档失败会明确提示；新 MSI 安装与原有用户数据不会因此被回退或删除。
此完整安装器不提供旧四文件补丁的“恢复原版”按钮，也不调用旧补丁恢复脚本。
如需回官方版，应选择更新构建的官方完整安装包；不要为了升级而先卸载。
Windows“已安装的应用”中的独立卸载沿用上游行为，会删除 Oink 本地用户数据。

运行时与发布说明
此修改版安装程序及 Oink 文件未做 Authenticode 签名，UAC 可能显示未知发布者。
微软 WebView2 运行时保留微软原始签名和许可，见 WebView2-LICENSE.txt。
WebView2 的 Microsoft Defender SmartScreen 可能向微软发送安全相关信息，详见 WEBVIEW2-NOTICE.txt。
不会安装信任证书、降低文件权限或更改持久 PowerShell 执行策略。
