# ポインター軌跡拡張版（第三者による変更版）

[Oink v0.3.4](https://github.com/oinkvm/oink/tree/v0.3.4) を基にした **0.3.4-inhouse.110（build 110）** です。公式リリースではありません。元の説明、著作者表示、ライセンスは下に残しています。

[このフォークの Releases](https://github.com/xiaojiangqvq/oink/releases) から `PointerTrail-Setup.exe` を入手し、各 Windows PC で標準のセットアップウィザードに従ってください。完全な Windows x64 パッケージなので原版の事前インストールは不要です。Microsoft 公式 WebView2 オフラインランタイムを同梱し、ない場合だけ追加します。

既存の Oink がある場合は、次から選べます。

- **上書きインストール（既定）**：ペアリング、画面配置、設定を保持して更新します。
- **アンインストール**：Oink を削除します。
- **新規インストール**：既存のアプリを削除してから入れ直します。

**アンインストールと新規インストールではローカルのアプリ設定が削除されます。** 設定を残して更新する場合は上書きを選んでください。原版 0.3.4 build 108 と以前の個人用軌跡パッチからの更新に対応し、新しい上流バージョンへの上書きは保証していません。

完了後はスタートメニューから Oink を開きます。**設定 → キーボードとマウス** で、従来の円操作／移動時表示、独立した軌跡色、Windows 矢印の色とサイズを選べます。矢印はほかのアプリにも適用されますが、文字入力やサイズ変更のカーソルは変わりません。システムを選ぶと以前の矢印に戻せます。既存のログイン時起動設定は保持され、新規導入で必要な場合は設定から有効にできます。

今後は[このフォークの Releases](https://github.com/xiaojiangqvq/oink/releases) から手動更新してください。Windows の公式更新フィードは無効です。完全なソースとライセンスも配布します。[ビルド手順](packaging/trail-installer/BUILDING.txt)。macOS パッケージはなく、クリーンな Windows PC での新規インストール実機テストはまだ完了していません。

# Oink — Oink Is Not only a KVM

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語** | [한국어](README.ko.md)

Oink は「Oink Is Not only a KVM」の略で、複数の Windows と Mac のあいだにピアツーピアの共有ネットワークを構築するモダンなソフトウェアです。どのデバイスのキーボード・マウス・トラックパッドでも近くの任意のデバイスを操作でき、どこでも統一されたネイティブな操作感を保ちます。複数のデバイスの音声を 1 台のデバイスにつないだスピーカーやヘッドホンで再生でき、クリップボードの共有とデバイス間のドラッグ＆ドロップ、ローカルネットワーク上のデバイスの自動検出に対応し、通信はデフォルトで暗号化されます。

## インストール

Windows 変更版と対応するソースコードは[このフォークの Releases](https://github.com/xiaojiangqvq/oink/releases) から入手できます。[上流の Releases](https://github.com/oinkvm/oink/releases) では原版とその Mac パッケージを配布しています。

対応 OS とバージョン：

- **Mac（上流のみ）**：Apple シリコン（arm64）、macOS 14.2 以降。Intel（x64）、macOS 14.2 以降（未テスト）。この変更版は Windows パッケージのみです。
- **Windows**：x64、Windows 10 1809（ビルド 17763）以降、または Windows 11。22H2 より前の Windows 10 バージョンは未テストです。拡張版には公式 WebView2 オフラインランタイムを同梱し、Windows LTSC などランタイムがない環境で追加します。

SmartScreen に「Windows によって PC が保護されました」と表示された場合は、選択肢が表示されたときに限り **詳細情報 → 実行** を選んでください。UAC では発行元が不明と表示されることがあります。

## よくある質問

**Oink は Deskflow をベースにしていますか、または Deskflow と互換性がありますか？**\
いいえ。Oink はゼロから作られたプロジェクトで、独自のピアツーピア（クライアント／サーバー型ではない）プロトコルを使っており、他のソフトウェア KVM とは互換性がありません。

**どれか 1 台をコントロール側として指定する必要がありますか？**\
いいえ。Oink はピアツーピア設計なので、どのデバイスにつないだキーボードとマウスでも他のデバイスを操作できます。

**トラックパッドのジェスチャーは共有できますか？**\
はい。ただし Windows のタッチパッドはテストされていません。

**OS をまたいだクリップボード共有やデバイス間のドラッグ＆ドロップに対応していますか？**\
はい。クリップボードはデバイス間で自動的に同期され、テキスト・画像・ファイルをあるデバイスから別のデバイスへ直接ドラッグできます。Chrome などのアプリに直接ドロップすることもできます。

**個人利用や商用利用のためにライセンスを購入する必要はありますか？**\
いいえ。Oink は GPL-3.0-only（追加条項付き）で公開されている自由ソフトウェアで、個人・商用を問わずどんな目的にも、追加のライセンスなしで利用できます。Oink やその改変版を配布する場合は、同じライセンスで完全なソースコードを提供し、原作者の表示とライセンス表記を残し、変更点を明示する必要があります。追加条項により、派生製品の宣伝に Oink の名称を使うこともできません。配布せず自分で使うためだけに改変する場合、これらの義務はありません。
